# Открытия ×5

В DVD-плеере и кассетной установке добавлен выбор ×1 / ×5.

- Набор стоит столько же, сколько пять одиночных открытий. Сначала расходуются активированные бесплатные открытия, затем Йеры за недостающие.
- Сервер проверяет баланс на весь набор до выдачи. Возврат от повторок не финансирует оставшуюся часть покупки.
- Пять результатов сохраняются одной транзакцией. Повторный или одновременный запрос с тем же номером не списывает баланс и не выдаёт предметы заново.
- DVD: одна короткая анимация чтения, затем пять карточек. Каждый диск можно рассмотреть отдельно; все экземпляры и повторки сразу находятся в коллекции.
- Кассеты: один договор и один код из трёх рун на весь набор. У каждого результата свой случайный выбор темы. Новые темы сохраняются, повторки возвращают обычную долю оплаченной цены. За бесплатные кассеты возврата нет.
- Ошибка кода закрывает все пять кассет с обычным возвратом половины оплаченной цены.
- Незавершённый набор кассет восстанавливается после перезахода. Номера запросов восстановления тоже запоминаются.
- Новый набор ×5 не покупается поверх незаконченного одиночного открытия.

Новые таблицы `gacha_batches` и `gacha_batch_requests` регистрируются перед существующим `Base.metadata.create_all`. Старая схема одиночных открытий сохранена.

API: `/api/gacha/dvd/open-five`, `/api/gacha/themes/buy-five`, `/api/gacha/themes/unlock-five`.

Изолированная полная локалка: http://127.0.0.1:5190/studio-live-preview.html . Здесь магазин, диски, Бекович, сад и Яабик используют отдельный SQLite API на 8093; остальные разделы предоставляются существующим демонстрационным стендом. Рабочая БД, Telegram и production `main.py` не запускаются. Обычный прокси проекта на 8080 не менялся.

Находки теперь открываются отдельным экраном инвентаря (`Findings.jsx`), без сцены лавки. Осмотр жетонов и считывание флешек сохранены.

Проверки: `tests/test_gacha_batch.py` — оплата, смешанные бесплатные открытия, недостаточный баланс, повторки, ошибки кода, восстановление, одновременные запросы и HTTP API.
