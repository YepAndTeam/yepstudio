# Раздельное оформление — обратимый эксперимент

Профиль → Настройки → «Где работает кассета» → «Темы только внутри игр и у Яабика».

- По умолчанию ВЫКЛЮЧЕНО: остаётся прежнее оформление всего приложения.
- Во включённом режиме Студия, Сообщество, Профиль и меню Игр используют базовую светлую/тёмную тему.
- В открытой игре (также режиме с дисками и саду) и комнате Яабика включается выбранная коллекционная кассета.
- Выключение сразу возвращает прежний режим. Серверная выбранная кассета, собственность, выпадение и цены не меняются.
- В профиле и коллекции имя выбранной кассеты отображается отдельно от применённой палитры (`selectedTheme` / `theme`). Фоновая музыка следует фактически включённой теме.
- Настройки `themeMode` и `baseTheme` живут в существующем `yab_preferences` на этом устройстве.

Проверено в настоящих компонентах через изолированный studio-preview: Nyan → Профиль dark → меню игр dark → Дино nyan → Студия dark → Яабик nyan → выключение режима возвращает nyan в Настройках.

## Лаборатория и аниме-эскиз

`http://127.0.0.1:5187/theme-preview.html`

Лаборатория не обращается к API и не сохраняет настройки: выбери кассету, базовую тему, режим, затем переходи между Студией, игровой сценой и комнатой Яабика. Размеры 320/360/420.

«Сакура / Письма сакуры»: оригинальный первый эскиз с кремовыми панелями, пыльной розой, сиреневым небом, лепестками, пиксельной кассетой и отделкой Яабика. CSS импортируется только в dev-лаборатории. Не добавлена в каталог выдачи, гачу, серверный список THEMES или экономику. Музыки и полных скинов всех игр пока нет — направление нужно сначала оценить.

Файлы: `themeScope.js` (чистое правило выбора), preferences/store/App/Game (интеграция), `sakuraTheme.css` и `themePreview.*` (локальный эскиз).
