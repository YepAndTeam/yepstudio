# Бейджики — оформление

Локальная галерея: http://127.0.0.1:5187/badge-preview.html. Отдельная dev-only страница, без API и изменения настоящего профиля/инвентаря. Примерка применяется только к демонстрационной карточке. Ссылка есть в панели макета Бековича.

Шесть временных исследований: архивный титан, ночной корпус, светлая сервисная эмаль, латунь Бековича, стальная мастерская, мятный Яабик. Это материалы и семейства дизайна, а не редкости и не шкала цены. Общие элементы: шильдик с утопленной эмалью, мелкие крепления, боковая цветная метка, оригинальная пиксельная эмблема, двухчастная надпись, серия и демонстрационный номер. Названия в badgeStudies.js временные, заменяются пользовательскими списками позже.

StudioBadge.jsx/CSS — компонент с полным размером, компактным профилем и пиктограммой для инвентаря/выпадения. Лёгкий блик играет только один раз при появлении и отключается при prefers-reduced-motion. Оформления имеют собственную контрастную палитру; внешнее окружение подстраивается под темы приложения. Используются локальные SVG/CSS и существующие шрифты без новых зависимостей и внешних изображений.

В макете Бековича обновлены пиктограмма награды, показ полученного бейджика и вид на тестовом профиле. Реальная выдача, серверная уникальность, новые словари надписей, торговля и оценка бейджиков сюда не входят.
