# После полуночи / Неон Токио

- Игра `drive`: свободное руление пальцем, удержание кнопок или стрелки/A/D. Пробел ставит паузу и продолжает заезд.
- При уходе из приложения заезд автоматически ставится на паузу. Возврат требует нажатия «Продолжить».
- Очки: дистанция / 12, монетка +15, обгон +5, близкий обгон дополнительно +10. Монетки не зачисляют Йеры.
- Результат сохраняется с серверным `run_id` в недельный и общий рейтинг. При ошибке можно повторить сохранение того же заезда.
- `neon` — редкая тема «Неон Токио». Меняет палитру приложения, трассу и автомобиль (пиксельная интерпретация Skyline R34). В коллекции есть отдельная иллюстрация и описание кассеты.
- Музыка темы в гонке: выбранная пользовательская мелодия, темп +30%, тон −3 полутона, без фоновых инструментов. Непрерывный AudioBuffer-loop; пауза, выключение звука, настройка фоновой музыки и выход из игры останавливают воспроизведение.
- Шансы групп прежние: обычные 70%, редкие 25%, мифические 5%. Три редкие темы равновероятны: по 25/3%; интерфейс округляет до ≈8,33%. За повторку неона возвращается 50 Йер при цене кассеты 100.
- Новая тема не выдаётся автоматически старым аккаунтам. На локальном стенде все темы доступны для проверки.
- Для релиза нужны одновременно backend и собранный frontend (`npm run build` из frontend). Новые таблицы не требуются.

Локальный стенд: `/studio-preview.html?scene=drive&theme=neon` (Vite, только development).
Рисование Canvas без внешних ассетов: максимум 30 кадров/с, ограниченное число машин и монет, без циклов отрисовки на стартовом экране и паузе.
