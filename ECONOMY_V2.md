# Обновление экономики

Ежедневные задания: три цели на 30/30/40 Йер, базовый дневной лимит 100. Бонусы дисков считаются отдельно. Добавлены задания гонки, новые короткие цели по всем играм. При обновлении текущий набор дня сохраняется, уже выполненные задания получают только разницу до новой суммы, один раз в той же транзакции.

Вход: серия из семи дней по 10/20/30/40/50/60/70 Йер. После пропуска серия начинается заново. День меняется в 00:00 UTC+5. Сегодняшний уже полученный вход не пересчитывается.

Достижения всех пяти игр: 10/50/100/250/500/1000 за шесть уровней (1910 суммарно). Пороги прежние, старые выплаченные уровни сохраняются, повторной выплаты нет.

Полная коллекционная полка: 100000 Йер вместо 1000, однократно за игру. Уже выданные награды за полки повторно не начисляются. Закрытый секретный подарок без изменений.

При первом запуске обновления initialize_economy фиксирует существующих пользователей в economy_welcome_v2 и сохраняет маркер economy-rebalance-v2 в meta. Им положено 5000: 2500 за трудности с балансом, 500 за изменение заданий, 1000 за достижения и 1000 за обновление недельных призов/рекордов. Если прежние 4000 уже получены, economy_record_adjustments защищает доплату 1000 от повторов, чек снова становится непрочитанным. Позднейшие регистрации получают только стартовые 2000. Начисление при первом GET /api/me, атомарно с записью paid_at; повторные входы, перезапуски и два устройства не повторяют платёж. Чек сохраняется в почте, прочтение не начисляет деньги. Стартовый баланс и компенсация не получают бонусов дисков; обе категории видны в бухгалтерии. Новая таблица создаётся штатным create_all. Production DB при разработке не вызывается.

Скачки: убран верхний лимит 25 Йер, минимум 1 целая Йера. Сохраняются баланс, обеспечение выплат резервом, одна действующая ставка на пару с возможностью замены до закрытия, запрет админских тестовых денег. Пополнение фонда админом имеет прежние отдельные правила.

Локальная проверка: /studio-preview.html?scene=economy&theme=dark — новый конверт; daily / daily7 — вход; игровые задания и полки используют новые награды.

Недельные призы: 1-е 1000, 2-е 750, 3-е 500, 4-е 350, 5-е 250, 6–10-е по 100 за каждую игру. Прежняя логика равных мест сохраняется. Уже закрытые недели не пересчитываются.

Общий рекорд: +1000 за строгое превышение существующего глобального максимума обычной игры. Если игрок уже владеет максимумом (включая ничью), требуется новый score*10 >= previous_best*11, то есть рост минимум 10% с округлением порога вверх. Чужой рекорд достаточно строго превысить. Первый результат пустой таблицы, ничья, старый результат без серверного run_id, режим с диском, повтор отправки и невозможная длительность Dino не оплачиваются. Проверка и начисление в той же транзакции под score_write_lock. global_record_awards с PK result_id хранит чек; бухгалтерия отдельно показывает рекорды, бонусы дисков на эту выплату не действуют. В ответе score поле record_reward, на экранах игр виден размер начисления.
