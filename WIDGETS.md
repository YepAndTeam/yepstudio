# Виджеты партий и игровые настройки

## Как пользоваться

После деплоя игрок нажимает /start или /play в личном чате с ботом.
Появляется один главный виджет без отдельного приветственного сообщения:
студия / профиль / партия с другом / друзья / турниры / почта.
Главная карточка показывает имя, число непрочитанных уведомлений, ожидающих
приглашений и ближайший активный турнир. Обновление — вручную, без опроса сервера.
Партия с другом → шахматы / шашки → список соперников
по пять на странице → приглашение. Получатель видит виджет с кнопками
«Принять» и «Отклонить». Автор может отменить приглашение. После принятия
оба видят «Открыть партию»: мини-приложение открывает одну общую партию.
Цвета назначаются случайно. Ставок Йеры в этом сценарии нет.

В список входят пользователи, которые нажали /start или /play после этого
обновления, не заблокировали бота и включили уведомления в настройках студии.
Telegram запрещает боту начинать личный диалог без действия пользователя.
Показывается имя игрока, без номера телефона или внешних контактов.

Приглашение живёт 30 минут. У автора максимум три ожидающих приглашения,
интервал новых приглашений — 30 секунд. Повтор webhook-запроса и повторное
принятие не создают вторую партию. Уведомления отправляются после фиксации
приглашения, вне транзакции. При сбое доставки есть явная кнопка повтора.
Если процесс оборвался во время отправки, через минуту обновление виджета
позволяет повторить доставку. При неопределённом сетевом результате возможна
повторная карточка того же приглашения, но партия останется одна.

## Ограничения Telegram

Используется Bot API 10.4, метод sendWidget. В рабочей среде доступны личные
чаты с ботом. Обычный select и текстовые поля внутри виджетов не поддерживаются:
выбор соперника реализован кнопками со страницами. Для старого клиента/API
сохраняется кнопка открытия обычного приложения и сообщение о недоступности.
Описание: https://core.telegram.org/bots/widgets

HTML хранится в widgets/board.html, проверяется размер до 32 КБ и сжатие
zlib до 4 КБ. Имя игрока вставляется через textContent. chat_data до 1024 байт.
Состояние обновляется по действиям, без фонового опроса. aiogram 3.22
получает неизвестный ему widget_query через отдельный обработчик сырого
webhook после проверки существующего секретного заголовка. Для новых методов
используются прямые вызовы Bot API; токен не выводится в логи.

На старте приложения регистрируются новые таблицы bot_contacts,
board_invitations, board_widget_sessions, board_widget_queries и отдельная
блокировка board_widget_lock. Экономическая блокировка и балансы не меняются.
Флаг widget_query явно включается при регистрации webhook. Существующие
партии шахмат и шашек сохраняются.

Локальный стенд: http://127.0.0.1:5187/widgets-preview.html
Он использует настоящий HTML виджета с подставным TelegramWidget и двумя
тестовыми игроками. Сообщения в Telegram не отправляет. Реальный клиент
Telegram и доставка проверяются после деплоя двумя аккаунтами через /start.

## Размер поля и Тетрис

Профиль → Настройки → Размер игрового поля: масштаб 60–100% и максимальная
ширина авто / 320 / 420 / 640 px. Общая настройка хранится на устройстве,
сохраняет пропорции поля и не меняет внутреннее разрешение, физику и очки.
Кнопка сброса возвращает старые размеры.

В Тетрисе удержание ▼ или свайп вниз с удержанием ускоряет падение.
Отпускание, отмена касания, потеря фокуса и сворачивание сбрасывают ускорение.
Накопленное время обычной гравитации при включении ускорения обнуляется,
чтобы фигура не проваливалась сразу на много клеток. Пробел на клавиатуре
сохраняет отдельный мгновенный сброс.

Главное меню и экраны выбора обновляют ту же карточку. Вложенное меню возвращается кнопкой «Главное меню». В ожидающем приглашении сначала отменяют/отклоняют его, чтобы не потерять управление им. При недоступности Widget API /start отправляет обычную кнопку открытия приложения. Код уже отправленного виджета Telegram не заменяет: после деплоя нужен новый /start. Локальный стенд: http://127.0.0.1:5187/widgets-preview.html; реальные сообщения и API Telegram он не вызывает.
