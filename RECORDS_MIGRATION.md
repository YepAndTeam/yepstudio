# Рекорды v2: автодеплой и однократный сброс

В этой версии запуск сервера **не сбрасывает рекорды и не начисляет старую компенсацию**.
Новые таблицы создаются обычным `Base.metadata.create_all`, а миграция старой `scores`
защищена постоянным маркером. Новых зависимостей нет.

## Порядок на Render

1. Запушить все изменённые и новые файлы в GitHub и дождаться успешного автодеплоя.
2. Полностью перезагрузить Mini App, войти как администратор, открыть «Профиль».
3. В блоке «Обновление рекордов · админ» нажать «Закрыть приём и рассчитать».
   Это приостановит начало и сохранение забегов. Бот, форум и новости продолжат работать.
4. Проверить таблицу выплат. «Скачать архив и расчёт» сохраняет дополнительную копию.
5. Нажать «Сбросить рекорды с компенсацией». Архив, выплаты, журнал операций,
   очистка недельных/общих рекордов и переключение поколения записей выполняются
   в одной транзакции. При ошибке всё откатывается.
6. Нажать «Открыть приём результатов». Начать новый забег для проверки.

Повторное применение не выдаёт награды заново. Если таблицы/балансы изменились
после расчёта, применение отклонится: нужно обновить расчёт. Игры, начатые до
сброса, не могут записать результат в новую таблицу. Старые вкладки нужно обновить.
Не удаляйте таблицы `meta`, `record_resets`, `game_results`, `jera_tx`.

## Компенсация

- 1 место — 100 Йер; 2–3 — 75; 4–10 — 50; остальные с положительным рекордом — 20.
- Равные очки дают равное место (1, 1, 3), отдельно в каждой игре.
- Для сравнения берётся максимум из текущей недельной и общей таблиц, не сумма.
- Ранее выплаченные `legacy:<игра>` вычитаются только из этой компенсации:
  доплата = `max(0, положено - ранее выдано)`. Уже начисленные Йеры не списываются.
- Выплаты разных игр суммируются. В Telegram рассылка не отправляется;
  появляется одно уведомление о суммарной доплате внутри приложения.
- Архив закрытых недель сохраняется для аудита, но удалённые модератором рекорды
  не восстанавливаются из него для новой выплаты.

## Общая модель

`game_runs` выдаёт серверный идентификатор забега. `game_results` хранит один принятый
результат. Один запрос обновляет недельный и общий максимум; если забег начался и
закончился внутри действующего турнира, обновляет также его максимум.
Все результаты турнира доступны через `scope=tournament&tournament_id=...`.
Планирование турниров, голосование, баннер и турнирные призы — следующий этап:
эта миграция не запускает 48-часовой отсчёт.

Турниры задаются сервером в `tournaments`: `id`, `game`, `title`, `starts_at`,
`ends_at` в UTC, `cancelled`. Перед разовым сбросом не должно быть назначенных
или активных турниров. Модерация инвалидирует результаты и удаляет их из всех
трёх рейтингов. Конкурирующие записи и сбросы сериализуются на строке блокировки.

## CLI, если используется Shell Render

```sh
python reset_records.py --maintenance on
python reset_records.py --preview backups/records-v2.json
python reset_records.py --apply backups/records-v2.json
python reset_records.py --maintenance off
```

Preview ничего не меняет и не перезаписывает существующий файл.
Apply требует уже запущенную v2 и включённое обслуживание.

## Проверки

```sh
python -m unittest discover -s tests -v
cd frontend
npm run build
```

Тесты используют отдельные SQLite-базы; с рабочей PostgreSQL они не соединяются.

## Магазин тем

- Кассета стоит 100 Йер. Выпадение: обычные 70% (по 35% Ретро/Терминал),
  редкие 25% (по 12,5% Тетрис/Nyan Cat), мифические 5% (Какашечки).
- Возврат за повторку гарантированный: 25 / 50 / 100 Йер. За неверные руны — 50.
- Цена, случайный выбор, право применения и все движения Йеры проверяются сервером.
  Браузер больше не определяет полученную тему и не хранит коллекцию как источник истины.
- При ПЕРВОМ старте этой версии существующие в БД аккаунты однократно получают
  обычные и редкие темы. Созданные после этого аккаунты получают только тёмную и светлую.
  Бесплатная мифическая тема из прежнего просмотра не переносится.
- Незавершённая покупка сохраняется. После перезагрузки «Продолжить кассету»
  восстанавливает её без нового списания, даже если баланс уже меньше цены.
- История открытий и коллекция доступны на другом устройстве того же аккаунта.
- Во время обслуживания рекордов покупки/открытия временно приостановлены,
  чтобы подготовленный расчёт компенсации не менялся из-за покупок.
- При деплое необходимо включить новые файлы shop_service.py и tests/test_shop.py.

## Письмо с компенсацией

При применении сброса вместе с выплатами создаётся персональное письмо.
При следующем входе или возвращении в приложение получатель видит конверт.
Чек показывает игру, место, рекорд, положенную награду, прежнюю выплату и доплату.
«Спасибо, получил!» сохраняет прочтение на сервере; «Позже» оставляет письмо непрочитанным.
Повторно чек доступен в «Профиль → Письма от студии». Чтение не меняет баланс.
Если сброс выполнен до установки этой версии, письма восстанавливаются из архива
однократно, с сохранением уже отмеченного прочтения. Письма получают участники с
положительной доплатой. Новые игроки без компенсации не увидят чужое/пустое письмо.
В деплой включить compensation_service.py, CompensationMail.jsx и тесты.

## Турниры

После деплоя: сначала завершить сброс/компенсацию и открыть приём результатов.
Затем «Профиль → Турниры · админ → Создать турнир» открывает регистрацию.
Первый турнир сервер принудительно делает Dino / 48 часов / 0 Йер.
Ссылка и подготовка поста доступны сразу. Отсчёт ещё НЕ идёт.
Когда участники собраны, кнопка «Запустить на 48 ч» задаёт настоящий старт/финиш.
Регистрация возможна и во время турнира, но учитываются только забеги после неё.

Призы: 1-е место — Какашечки (или 200 Йер за уже полученный мифик),
2-е — 150, 3-е — 100, 4-е — 75, 5-е — 50. При равенстве очков выше раннее
время достижения; затем Telegram ID для полностью одинаковых времён.
Итоги проверяются сервером раз в 30 секунд и при обращении к турнирам/профилю.
Если бесплатный Render спал, итог будет выдан после пробуждения. Дедлайн приёма
результатов всё равно проверяется по времени сервера. Повторных выплат нет.
Dino начинает отсчёт после получения серверного ID, чтобы холодный старт Render
не приводил к ложному отклонению результата. В турнире есть проверка очков по времени забега.

После завершения игроки голосуют за следующую игру: один голос на аккаунт,
который можно изменить. При создании следующего турнира голосование закрывается.
Уникальный победитель выбирается сервером; при ничьей админ выбирает из лидеров.
Следующие турниры платные: по умолчанию форма предлагает 50 Йер, можно изменить.
Взнос списывается один раз на весь турнир и не распределяется как призовой фонд.
При отмене регистрации или активного турнира взносы возвращаются один раз.
Глобальный сброс рекордов нельзя запустить при открытом турнире/регистрации.

Ссылка для канала: https://ваш-домен/tournaments/ID. Страница доступна без входа,
содержит Open Graph и PNG-обложку 1200×630, а кнопка ведёт в Mini App на этот турнир.
«Подготовить пост» открывает стандартный выбор чата Telegram с текстом и ссылкой;
приложение само ничего в канал не отправляет. Реальное появление карточки проверять
после деплоя: Telegram должен иметь доступ к публичному URL и включённые превью.

Добавленные файлы для деплоя: tournament_service.py, TournamentBanner.jsx,
TournamentAdmin.jsx, frontend/public/tournament-*.png, tests/test_tournaments.py.
