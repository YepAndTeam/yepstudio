# Лавка Бековича

Лавка подключена к основному приложению: **Магазин → Лавка Бековича**.
Находки доступны через **Профиль → Инвентарь → Находки Бековича**.
Калькулятор ящиков: **Настройки → Бекович и шансы** и кнопка внизу лавки.

## Сделки

- Сервер принимает ID 1–3 экземпляров; редкость, принадлежность и награду клиент не задаёт.
- Подходят новые диски без активации, полки, активного объявления и незавершённого обмена.
- Состав (игра + редкость, с учётом повторяющихся копий) сохраняется на сервере отдельно для каждого игрока. Перестановка и замена одинаковыми копиями не переигрывают предложение или отказ.
- Оценка сообщает только ящик, вероятность отказа и шансы. Содержимое хранится сервером.
- Подтверждение под общим блокировщиком экономики атомарно переводит диски в `traded`, сохраняет сделку и выдаёт находку. Сбой откатывает всё.
- Один `request_id` не выдаёт повторную награду, даже при одновременных запросах. Повторное списание тех же экземпляров с другим номером запрещено.
- Рабочая база, бот, деплой и реальные Telegram-сообщения во время разработки не используются.

## Награды

- Йеры: 5–50, веса 46..1, средняя выплата 20. Начисление вместе со сделкой, с записью `JeraTx` категории «Лавка Бековича».
- Знакомая кассета: одна из уже открытых коллекционных тем, сразу конвертируется в 25/50/100 Йер по редкости. Если у новичка только базовые темы — базовая кассета и 25 Йер.
- USB: темы 30%, DVD 70%; пустая 50%, иначе 1/3/5/10 открытий с шансами 60/30/9/1%. Содержимое не передаётся клиенту до чтения. Считывание добавляет открытия ровно один раз; затем плееры расходуют их до списания Йер.
- Эпическое семя: одно из двух эпических растений, добавляется в существующий сад без изменения остальных семян и грядок.
- Турнирный купон автоматически покрывает один взнос в платный турнир. На бесплатном не расходуется, при повторной регистрации не списывается снова, при отмене возвращается. Возврат Йер за купон не начисляется.
- Жетон: 50% список сообщества / 50% генератор, шесть независимых оформлений металла. Общая надпись уникальна среди всех выданных жетонов: нормализация регистра и пробелов, серверная проверка и уникальный индекс БД. Закрепление разрешено только владельцу.
- Наживка и нашивки сохраняются как предметы в сумке. Рыбалка и установка нашивок пока не реализованы; они не дают скрытых эффектов.

Все надписи и оформления хранятся в общем `bekovich_catalog.json`, который читают сервер и фронтенд. Номер и оформление выданного жетона неизменны. Тестовая смена титула отсутствует в настоящей лавке.

## Запуск

Изменения схемы только добавочные: таблицы `bekovich_offers`, `bekovich_deals`, `bekovich_items`, `studio_badges`, `bekovich_wallets` регистрируются перед существующим `Base.metadata.create_all`. Переносить записи из локального макета не нужно: это вымышленные предметы.

Фронтенд собирается обычным `npm run build` в `static`; стандартный локальный прокси остаётся на порту 8080. Не запускайте `main.py` ради теста с рабочим `.env`.

Отдельный проверочный стенд: `http://127.0.0.1:5190/bekovich-live-preview.html`, API 8093. Он использует только SQLite `C:/Users/User/Documents/Codex/2026-11-11/q/work/bekovich-playtest.sqlite` и тестового игрока. Обычный визуальный макет остаётся на `/bekovich-preview.html`.

## Проверки

Тесты `tests/test_bekovich.py`, `tests/test_bekovich_api.py`: владение, занятые диски, скрытые результаты, повторные и одновременные подтверждения, откат при сбое, сохранение USB, списание открытий реальными плеерами, уникальность титулов, сад, купоны и отмена турнира.

Фронтенд и сервер сверены для всех 258 сочетаний редкостей. Поддерживаются 95% отказа за один обычный/секретный и обновлённая кривая для редких и эпических дисков.
